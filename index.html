Primero, entendamos la lógica

🦊

Fox dice:
¡Soy Fox! Hoy vamos a guardar un cliente de verdad. Primero sigue el recorrido de sus datos.

En memoria, un objeto conserva datos mientras se ejecuta el programa. MySQL permite guardarlos y consultarlos después de cerrar Java. MVC distribuye el trabajo; JDBC permite comunicarnos con la base de datos.

Vista

Muestra los campos y el botón. El usuario escribe aquí.

Controlador

Escucha el clic, lee los campos y llama al modelo.

Modelo

Conserva los datos y ejecuta el INSERT usando la conexión.

Utilidades

Abre la conexión con MySQL usando el driver JDBC.

Ejemplo: Ana López escribe su nombre y teléfono. El controlador los pasa al modelo mediante setters. El modelo abre una conexión y ejecuta el INSERT. MySQL crea una fila. El controlador muestra el resultado.

Un setter solo cambia un atributo del objeto. guardarcliente() es el método que envía los datos a MySQL. El conector es una biblioteca .jar; no es el servidor de base de datos.

clientes.sql
CREATE DATABASE IF NOT EXISTS mvc_clientes
CHARACTER SET utf8mb4;
USE mvc_clientes;

CREATE TABLE IF NOT EXISTS clientes (
    cli_codigo INT AUTO_INCREMENT PRIMARY KEY,
    cli_nombre VARCHAR(100) NOT NULL,
    cli_telefono VARCHAR(30) NOT NULL
);

-- Ejecutar después de guardar desde Java:
SELECT * FROM clientes;

El código es AUTO_INCREMENT: Java no lo envía. El teléfono es texto porque puede incluir “+”, espacios y ceros al inicio. El nombre y teléfono no admiten NULL; esta práctica aún no incorpora validación de campos vacíos.

MISIÓN 05 / 10

Crear la clase de conexión

🦊

Fox dice:
Enlace abre la puerta. Si no puede abrirla, el error debe llegar al controlador.

En el paquete utilidades, crea una Java Class llamada conexion y usa este código:

conexion.java
package utilidades;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class conexion {
    // Cambia estos valores según tu servidor local.
    static String bd = "mvc_clientes";
    static String user = "root";
    static String pass = "";
    static String host = "jdbc:mysql://localhost:3306/" + bd;

    public static Connection Enlace() throws SQLException {
        // Busca el driver dentro del JAR agregado al proyecto.
        try {
            Class.forName("com.mysql.cj.jdbc.Driver");
        } catch (ClassNotFoundException ex) {
            throw new SQLException("Falta agregar el conector MySQL al proyecto", ex);
        }
        // Devuelve una conexión abierta; si falla, propaga el error.
        return DriverManager.getConnection(host, user, pass);
    }
}
ParteSignifica
jdbc:mysql://Protocolo JDBC para MySQL.
localhostEl servidor está en la misma computadora que Java.
3306Puerto del ejemplo; cámbialo si tu servidor usa otro.
mvc_clientesNombre exacto de la base creada.
root / contraseña vacíaValores de práctica local; ajusta a tu configuración. No los uses como configuración de producción.

Connection representa la sesión abierta. DriverManager.getConnection() intenta conectarse. throws SQLException permite avisar al método que llamó si ocurre un problema.

Respecto al esquema inicial, simplificamos Enlace(Connection conn) a Enlace(). Ya no necesitamos sta(): el modelo preparará su sentencia a partir de la conexión.

MISIÓN 06 / 10

Crear el modelo de clientes

🦊

Fox dice:
Tenemos dos momentos: cargar el objeto y guardarlo. ¡Son operaciones distintas!

Crea clientesmodelo dentro de modelo.

clientesmodelo.java
package modelo;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.SQLException;
import utilidades.conexion;

public class clientesmodelo {
    // Estado del objeto: los datos del cliente que vamos a guardar.
    private String nombre;
    private String telefono;

    public String getNombre() { return nombre; }
    public void setNombre(String nombre) { this.nombre = nombre; }
    public String getTelefono() { return telefono; }
    public void setTelefono(String telefono) { this.telefono = telefono; }

    public int guardarcliente() throws SQLException {
        // Los signos ? son lugares reservados para los valores.
        String sql = "INSERT INTO clientes(cli_nombre, cli_telefono) VALUES (?, ?)";

        // Al salir del bloque se cierran st y conn, incluso si hay un error.
        try (Connection conn = conexion.Enlace();
             PreparedStatement st = conn.prepareStatement(sql)) {
            st.setString(1, nombre);   // Primer ? : nombre.
            st.setString(2, telefono); // Segundo ? : teléfono.
            return st.executeUpdate(); // Devuelve la cantidad de filas insertadas.
        }
    }
}
  1. Los setters reciben los datos que vienen de la vista.
  2. El SQL define la tabla, las columnas y dos lugares reservados: ?.
  3. conexion.Enlace() abre la conexión.
  4. prepareStatement(sql) crea la sentencia parametrizada.
  5. setString(1, nombre) y setString(2, telefono) asignan los valores en orden; los índices empiezan en 1.
  6. executeUpdate() ejecuta el INSERT. Con la configuración JDBC predeterminada de autocommit, se confirma al terminar correctamente.
  7. El bloque try (...) cierra la sentencia y la conexión automáticamente.
Usamos PreparedStatement en lugar de concatenar los textos al SQL: un apellido como D'Ávila se envía como dato. Cerrar solo la sentencia no cierra la conexión. Por eso aquí cerramos ambas.

El modelo devuelve el número de filas insertadas y propaga el error. El mensaje visual queda en el controlador, sin JOptionPane dentro del modelo.

MISIÓN 07 / 10

Crear el controlador

🦊

Fox dice:
Soy el mensajero: escucho el botón, tomo los textos y pido al modelo que guarde.

Crea clientescontrolador dentro de controlador.

clientescontrolador.java
package controlador;

import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.sql.SQLException;
import javax.swing.JOptionPane;
import modelo.clientesmodelo;
import vista.clientesvista;

public class clientescontrolador implements ActionListener {
    clientesmodelo modelo;
    clientesvista vista;

    public clientescontrolador(clientesmodelo modelo, clientesvista vista) {
        this.modelo = modelo;
        this.vista = vista;
        // Suscribimos este controlador al botón, una sola vez.
        vista.btnguardar.addActionListener(this);
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        Object p = e.getSource();
        if (p.equals(vista.btnguardar)) {
            // Leer los campos y cargar el objeto NO ejecuta SQL todavía.
            modelo.setNombre(vista.txtnombre.getText());
            modelo.setTelefono(vista.txttelefono.getText());
            try {
                int filas = modelo.guardarcliente();
                if (filas == 1) {
                    JOptionPane.showMessageDialog(vista, "CLIENTE GUARDADO");
                    vista.txtnombre.setText("");
                    vista.txttelefono.setText("");
                    vista.txtnombre.requestFocusInWindow();
                }
            } catch (SQLException ex) {
                JOptionPane.showMessageDialog(vista,
                    "No se pudo guardar: " + ex.getMessage());
            }
        }
    }
}

implements ActionListener indica que esta clase puede recibir eventos. addActionListener(this) la registra en el botón. e.getSource() identifica quién disparó el evento.

El controlador recibe las referencias del modelo y de la vista. No crea otra ventana: utiliza la que ya está abierta. Muestra “CLIENTE GUARDADO” únicamente después de insertar una fila.

En esta práctica pequeña, la operación se realiza en el hilo de eventos de Swing. Una conexión lenta puede congelar momentáneamente la ventana; para una aplicación real, se puede trasladar el acceso a la BD a SwingWorker.

Unir la vista, el modelo y el controlador

🦊

Fox dice:
Primero initComponents; después conectamos los objetos. ¡El botón tiene que existir antes de escucharlo!

Regresa a clientesvista.java. Agrega los imports indicados y reemplaza únicamente el constructor. No pegues otro constructor duplicado ni modifiques el bloque generado por NetBeans.

constructor.txt
// En clientesvista.java, antes de declarar la clase:
import modelo.clientesmodelo;
import controlador.clientescontrolador;

// Reemplaza el constructor del formulario por este:
public clientesvista() {
    initComponents(); // Primero deben existir los componentes.
    clientesmodelo modelo = new clientesmodelo();
    clientescontrolador control = new clientescontrolador(modelo, this);
    setLocationRelativeTo(null);
}

this representa el formulario actual. El modelo guarda el estado; el controlador recibe ambos objetos y se suscribe al botón.

Ejecuta clientesvista.java con Run File o establece vista.clientesvista como Main Class del proyecto.

Alternativa: vista completa sin diseñador visual

Si prefieres pegar una clase completa, crea una Java Class normal con este código. Es una alternativa al JFrame Form anterior: usa una sola versión de clientesvista. Los otros tres archivos no cambian.

clientesvista.java
package vista;

import controlador.clientescontrolador;
import modelo.clientesmodelo;
import javax.swing.*;
import java.awt.GridLayout;

// Alternativa completa escrita a mano, sin editor visual.
// Si usas el JFrame Form de NetBeans, sigue el paso 4 de la guía.
public class clientesvista extends JFrame {
    public JTextField txtnombre = new JTextField();
    public JTextField txttelefono = new JTextField();
    public JButton btnguardar = new JButton("Guardar cliente");

    public clientesvista() {
        initComponents();
        clientesmodelo modelo = new clientesmodelo();
        clientescontrolador control = new clientescontrolador(modelo, this);
        setLocationRelativeTo(null);
    }

    private void initComponents() {
        setTitle("Clientes | MVC + MySQL");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        JPanel panel = new JPanel(new GridLayout(3, 2, 10, 10));
        panel.setBorder(BorderFactory.createEmptyBorder(20, 20, 20, 20));
        panel.add(new JLabel("Nombre:"));
        panel.add(txtnombre);
        panel.add(new JLabel("Teléfono:"));
        panel.add(txttelefono);
        panel.add(new JLabel("Código automático"));
        panel.add(btnguardar);
        setContentPane(panel);
        setSize(440, 190);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new clientesvista().setVisible(true));
    }
}
